# nicklanng.github.io

Personal site and CV, built from Markdown with [single-page-markdown-website](https://www.npmjs.com/package/single-page-markdown-website).

## Edit and rebuild

1. Edit `index.md`, `styles.md`, or `print-styles.md`.
2. Run `npm run build`.
3. Copy the output to the site root: `cp build/index.html index.html`
4. Commit and push.
